国内 VPS 如何安装 V2Ray？

因为国内 VPS 连接 GitHub 不便，所以难以在线安装 V2Ray，此处介绍本地安装的方法。

在本地电脑上，从这里（https://t.co/cPvgY3k213）下载 V2Ray for Linux 的安装包，从这里（https://t.co/obDFjZ1lV2）下载安装脚本 `https://t.co/TsoSEG5qzh`，将它们复制到 VPS 上的 https://t.co/Fvy8pkATdy
